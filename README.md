# ViaLivre AI

Aplicação web que ajuda pessoas a decidirem o melhor horário para sair no trânsito com base em estimativa de tráfego e condições do trajeto.

O objetivo é reduzir atrasos e melhorar o planejamento do deslocamento diário.

---

## Problema

Muitas pessoas saem de casa sem saber:

- se o trânsito está congestionado
- qual o melhor horário para sair
- quanto tempo o trajeto pode levar
- se haverá atraso

O ViaLivre AI busca resolver esse problema com recomendações simples.

---

## Funcionalidades iniciais

- informar origem
- informar destino
- informar horário de saída
- simular nível de trânsito
- gerar recomendação automática
