# ViaLivre AI

Aplicação web que ajuda pessoas a decidirem o melhor horário para sair no trânsito com base em estimativa de tráfego, clima e tipo de transporte.

O objetivo é reduzir atrasos e melhorar o planejamento do deslocamento diário por meio de recomendações inteligentes.

---

## Demonstração

Frontend:
https://robersoncodes.github.io/vialivre-ai/

API local:
http://localhost:3000/api/analises

---

## Problema

Muitas pessoas saem de casa sem saber:

- se o trânsito estará congestionado
- qual o melhor horário para sair
- quanto tempo o trajeto pode levar
- como o clima impacta o trânsito
- se o tipo de transporte altera o tempo de viagem

O ViaLivre AI busca resolver esse problema com uma análise simples baseada em regras de negócio.

---

## Funcionalidades

- informar origem e destino
- informar horário de saída
- selecionar condição climática
- selecionar tipo de transporte
- simular nível de trânsito
- estimar tempo de deslocamento
- gerar recomendação automática
- histórico das análises
- limpeza do histórico
- dashboard com estatísticas
